# Inventory Order Management System

A simple Java console project built to practice core Java collections, generics, lambdas, streams, and `Optional`.

## Project Goal

This project manages:

- Products
- Inventory
- Customer orders
- Pending orders
- Processed order history

It is designed as a practice project for Java Collections and data handling.

## Features

- Add products
- Remove products
- Search product by ID
- Show all products
- Show low-stock products
- Show unique categories
- Sort products by price
- Sort products by name
- Calculate total inventory value
- Place customer orders
- Process orders in FIFO order
- Track processed order history

## Java Concepts Used

- `ArrayList`
- `HashMap`
- `HashSet`
- `Queue`
- `Deque`
- `Comparator`
- Generics
- Lambdas
- Streams
- `Optional`
